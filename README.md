# Praktikum VCS – PTI

## Deskripsi
Repository ini dibuat untuk memenuhi kegiatan Praktikum 1 mata kuliah yang mempelajari Version Control System (VCS). Praktikum ini bertujuan untuk mengenal GitHub sebagai tempat menyimpan, mengelola, dan mendokumentasikan kode atau berkas proyek.

## Tujuan Praktikum
- Memahami penggunaan repository di GitHub.
- Mengetahui fungsi file README.md.
- Mempelajari cara mengedit dan menyimpan perubahan menggunakan commit.
- Mengenal dasar-dasar version control.

## Kegiatan Praktikum
1. Membuat repository baru di GitHub.
2. Menambahkan dan mengedit file README.md.
3. Menuliskan deskripsi proyek.
4. Menyimpan perubahan menggunakan fitur commit.

## Hasil Praktikum
Berhasil membuat repository GitHub yang dilengkapi dengan file README.md dan minimal satu commit sebagai bukti perubahan.

- Program Studi: Pendidikan Teknologi Informasi (PTI)
- Kegiatan: Praktikum 1 – Membuat Repository
